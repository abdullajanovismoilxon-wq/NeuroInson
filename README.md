# NeuroInson — Multi-Functional AI Platform

NeuroInson — sun'iy intellekt xizmatlari (Chat, AI Prompt Assistant, Rasm va Video generatsiyasi, Loyihalar Markazi va avtomatik PPTX, DOCX, ZIP fayllar tayyorlash) platformasi.

## 🚀 Asosiy Imkoniyatlar

- **Neuroinson AI Chatbot**: Google Gemini 3.1 Pro/Flash modellarida ishlaydigan aqlli yordamchi.
- **AI Prompt Assistant**: Rasm va video yaratish uchun g'oyalarni Midjourney va FLUX promptlariga aylantirib beruvchi vosita.
- **Rasm va Video Generatsiyasi**: Fal.ai va Flux modellariga ulangan media generator.
- **Loyihalar Markazi**:
  - 📄 **Taqdimot Slaydlari (PPTX)**: Avtomatik tayyor PowerPoint `.pptx` fayl generatsiyasi.
  - 📝 **Kurs Ishi / Mustaqil Ish**: Avtomatik tayyor Word `.docx` hujjat generatsiyasi.
  - 💻 **Web App / Sayt Yaratish**: Avtomatik tayyor `.zip` sayt kodi arxivi.
  - 🤖 **Telegram Bot kodi**: Avtomatik tayyor Python `.zip` bot kodi.
